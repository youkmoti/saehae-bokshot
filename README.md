# 새해복샷! — 모바일 HTML5 게임

## 현재 상태
이 프로젝트는 대화에서 마지막으로 제작한 **v50 게임 소스**를 기반으로 한 첫 배포 준비본입니다. 게임 로직·가이드·효과음·내장 배경음악을 유지했고, 헤더의 영문 중복 문구를 정리했습니다.

아직 **6개 언어 완전 적용, 결과 카드 공유, 점수 흡수 애니메이션, 온라인 랭킹**은 이 버전에 구현되지 않았습니다. 해당 기능은 후속 개발 항목입니다. 실제 배포 전 휴대폰에서 동작을 확인하세요.

## 휴대폰으로 배포하기
1. GitHub 웹사이트에서 새 **private** 저장소를 생성합니다. 저장소 이름 예: `saehae-bokshot`.
2. 저장소의 **Add file → Upload files**에서 이 폴더의 `index.html`과 `README.md`를 업로드하고 Commit합니다. ZIP 파일 자체를 올리면 웹게임으로 배포되지 않습니다.
3. Cloudflare Pages에서 **Create project → Connect to Git**을 선택해 저장소를 연결합니다.
4. 정적 사이트로 배포합니다. 빌드 명령은 비워두고 출력 디렉터리는 프로젝트 루트(`.`)를 사용합니다.
5. 발급된 HTTPS 주소로 휴대폰에서 게임·음악·터치를 테스트합니다.

## 주의
- 브라우저의 로컬 파일 열기(`content://`)보다 HTTPS 배포에서 공유 기능이 안정적으로 작동합니다.
- 현재 음악은 HTML 내부에 포함된 버전이므로 파일이 큽니다.
- 랭킹은 별도 서버/DB와 점수 검증이 필요합니다.
- 게임 포털 입점 및 수익화는 별도 심사와 정책 확인이 필요합니다.
